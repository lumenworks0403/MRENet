## 明确的实现选择与边界

PDF 规定 SS2D 块包含选择性扫描、FFN、归一化、位置编码和残差连接，但没有完整指定扫描块的每个参数及初始化。
本版在 `rrs/selective_scan.py` 中实现四方向输入相关的状态递推，状态维数取 1，步长通过低秩投影及 softplus 产生。
四方向为行优先、列优先及其逆序，合并后进行 LayerNorm 和输出投影。
块使用 3×3 深度卷积位置编码和四倍通道 FFN。它实现了所描述的状态扫描机制，但不主张与未提供的训练实现逐参数或逐浮点等价。

扫描递推使用长度 64 的分块仿射前缀运算，无累乘再除法，也无额外扫描扩展依赖。
默认只在扫描块内关闭 autocast 并转 FP32，其余模块继续遵循 AMP。
卷积后的归一化默认使用 GroupNorm；全局池化分支在 batch size 1 下也可以训练。
`norm='bn'` 仅供对照，训练时 batch size 1 的 1×1 池化分支会受 BatchNorm 限制。

六路联合扫描结果先恢复到内部 replication-padding 后的尺寸，再裁回原尺寸，防止非整除宽高改变外部坐标。
RCA 以原始 logit 的 argmax 计算与 sigmoid 排序等价的索引，避免大正数 sigmoid 饱和导致的数值并列；报告的 scores 仍为 sigmoid 概率。
未开启 RCA 的 TM 消融按每组候选在有效 token 上的最大 sigmoid 概率选取，排除特殊 token、句号和 padding。

推理结果 `queries`、`scores`、`selected_boxes` 分别记录六组选择；`mask` 和 `prob_mask` 仅代表融合后的一个目标。
`boxes` 中的均值框只用于兼容原评估器的框诊断，来自六组各自选中的框，不参与掩码生成；论文方法以分割掩码为输出。
完整路径仅支持单目标 top1；基线的多目标能力不视作本方法的扩展验证。

## 权重与复现

保留 GroundingDINO 的预训练层键及共享框头，不重新创建五个额外解码层。
新 MCPE 结构的权重与旧像素原型不同，直接同架构加载会严格检查并在缺键、异形键时失败。
从 FPN 基线通过 `--init-from` 初始化时，整条像素支路重新初始化；优化器、epoch、best 不继承。
旧 Python 配置接口名保留兼容，新的论文命名在模式解析阶段转换为这些内部字段。

代码与单元测试不能证明论文报告的 mIoU、oIoU、参数量、FLOPs 或延迟已被复现。
本次未提供真实数据集、预训练文件和训练后的模型；需按完整配置重新训练及评估。

小样本迁移中，模型选择保留任何更高的原始验证 mIoU，停滞判定则要求相对前一次原始最佳值提高至少 0.1 个百分点。
阶段2学习率调整计数与累计停滞早停计数分别维护，避免每3次衰减清零后永远不能达到6次早停。
骨干参数在冻结阶段已加入独立优化器组，解冻时保留任务参数的 AdamW 动量。
抽样器要求输入为已清理的单目标数据；不将同一图像的多个表达计为额外独立标注。
