# RefSegRS 与 RRSIS-D 训练格式

两个数据集已转换为项目 `rrs/data.py` 接受的 JSONL，并新增训练配置。本次仅运行数据转换，没有运行测试、模型前向、训练或评估。

## 生成位置与数量

| 数据集 | 生成目录 | train | val | test | 总数 |
|---|---|---:|---:|---:|---:|
| RefSegRS | `data/RefSegRS/b0/` | 2,172 | 431 | 1,817 | 4,420 |
| RRSIS-D 清理版 | `data/RRSIS-D/b0/` | 12,170 | 1,738 | 3,477 | 17,385 |

每个生成目录包含 `train.jsonl`、`val.jsonl`、`test.jsonl`、`conversion_report.json` 和 `excluded_samples.jsonl`。JSONL 中的 image 路径相对于对应数据集根目录，配置已设置正确的 image_root。复制项目到服务器时，保留这些 JSONL 以及它们引用的原图目录。

## 转换与异常处理规则

- RefSegRS：按原始 TXT 保留完整表达，TIFF RGB 掩码取一个等价通道并二值化，再转为 COCO RLE；图像仍引用原始 TIFF。全部样本保留。
- RRSIS-D：按 refs 的 image_id、ann_id 关联图像与标注，使用官方 split；将 RLE 列表转为单个 RLE 字典。
- 两个数据集都从完整前景掩码计算像素 xywh 外接框，不复制 RRSIS-D 原始 xyxy 框。每条表达保留一个完整掩码，不拆分连通域。
- RRSIS-D 的 3 条空掩码和 14 条掩码／图像尺寸不匹配记录从生成划分排除。原始图像、标注、表达均未删除或改写；排除清单保留原因、尺寸、原始 annotation 和 reference。
- 没有使用框填充或 SAM 伪造缺失掩码，没有猜测裁剪／缩放规则，也没有将有目标表达改成无目标样本。

| RRSIS-D 划分 | 原始数量 | 空掩码排除 | 尺寸不匹配排除 | 保留数量 |
|---|---:|---:|---:|---:|
| train | 12,181 | 2 | 9 | 12,170 |
| val | 1,740 | 0 | 2 | 1,738 |
| test | 3,481 | 1 | 3 | 3,477 |

RRSIS-D 的 val/test 是清理后的子集，报告指标时需注明采用此版本，不能标为完整官方划分成绩。17 条记录的 ID、尺寸和文本见原兼容性检查报告，完整机器可读清单以 `data/RRSIS-D/b0/excluded_samples.jsonl` 为准。

## 直接启动 HED 训练

在已安装项目训练依赖和权重的环境中，从项目根目录运行以下命令。本次没有执行这些命令。

```bash
python tools/train.py --config configs/b0_hed_refsegrs.py
python tools/train.py --config configs/b0_hed_rrsisd.py
```

配置提供了三个已有模型模式，数据路径和 output_dir 均已独立设置：

| 模式 | RefSegRS 配置 | RRSIS-D 配置 |
|---|---|---|
| B0 | `configs/b0_refsegrs.py` | `configs/b0_rrsisd.py` |
| HED，无 DN | `configs/b0_hed_refsegrs.py` | `configs/b0_hed_rrsisd.py` |
| HED + MMSCopE + RefScoreHead，无 DN | `configs/b0_hed_mm_score_refsegrs.py` | `configs/b0_hed_mm_score_rrsisd.py` |

每个配置继承相应 RIS-LAD 配置中的模型开关和训练超参，使用 `hflip=0.0`、`postprocess=dict(mode='top1')`，不限制样本数。MMSCopE 模式仍需要项目已有的额外依赖。B0 与 HED 的 batch_size/grad_accum 继承各自旧配置，做模型对照实验时应按原项目要求统一。

训练过程中 val_data 指向验证集。需要最终测试集评估时，`tools/train.py --eval-only` 仍读取 val_data，应通过 `--opts val_data.path=.../test.jsonl` 指向相应测试 JSONL，训练选模型时不要切换到 test。

## 使用已有权重直接测试

将下方 `YOUR_TRAINED_CHECKPOINT.pth` 替换为本项目训练保存的完整 checkpoint 路径，在项目根目录运行。权重通过 `--resume` 加载，`--eval-only` 使程序在评估后退出，不进入训练循环：

```bash
python tools/train.py --config configs/b0_hed_refsegrs.py --eval-only --resume "YOUR_TRAINED_CHECKPOINT.pth" --opts val_data.path=data/RefSegRS/b0/test.jsonl output_dir=work_dirs/test_refsegrs gdino_ckpt=None
python tools/train.py --config configs/b0_hed_rrsisd.py --eval-only --resume "YOUR_TRAINED_CHECKPOINT.pth" --opts val_data.path=data/RRSIS-D/b0/test.jsonl output_dir=work_dirs/test_rrsisd gdino_ckpt=None
```

两条命令分别评估 RefSegRS 的 1,817 条、RRSIS-D 清理版的 3,477 条测试样本。如果两个数据集使用不同权重，分别填写对应路径。结果输出到终端，并写入对应 output_dir 的 `log.jsonl`，包含 mIoU、oIoU、Prec@0.5–0.9 等指标。`gdino_ckpt=None` 省去重复加载官方预训练权重，模型参数仍从 `--resume` 指定的完整训练 checkpoint 恢复。

checkpoint 必须含本项目的 `model` 权重字典；正常保存的 checkpoint 还含 `cfg`，入口会从中恢复 HED、DN、MMSCopE、评分头及相关模式配置。旧 checkpoint 缺少模式字段时按 False 处理，应依据真实训练配置显式指定，不能只凭文件名推断。图像尺寸、batch_size 等非模式参数仍采用当前配置，需要与原实验设置对齐。`--init-from` 用于训练初始化，不能代替这里的 `--resume`。

## 重新生成格式

生成脚本仅依赖 numpy、Pillow、pycocotools，不导入模型或训练代码：

```bash
python tools/prepare_remote_sensing.py
python tools/prepare_remote_sensing.py --dataset refsegrs
python tools/prepare_remote_sensing.py --dataset rrsisd
```

第一条生成两个数据集，后两条分别生成单个数据集。脚本默认从自身所在项目的 data/ 查找原始数据，也支持 `--data-root` 指定其它数据根目录。重复运行会覆盖 b0/ 下的生成 JSONL、转换报告和排除清单，原始数据保持不变。
